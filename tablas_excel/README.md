# Carpetas de tablas Excel

Estas carpetas estan pensadas para que el cliente mantenga una copia ordenada de los Excel maestros vigentes.

La aplicacion web no puede leer automaticamente archivos locales por seguridad del navegador. El flujo previsto es:

1. Sustituir el Excel correspondiente en esta carpeta.
2. Abrir la aplicacion.
3. Ir a `Tablas`.
4. Cargar ese Excel en la fila de la tabla correspondiente.

La aplicacion guarda en el navegador la configuracion y trazabilidad ligera. Las tablas grandes deben mantenerse como Excel maestros en estas carpetas o como JSON preimportados en `data/`.

Carpetas:

- `ALART`
- `ALHIS`
- `GCESP`
- `ALARTDV`
- `CPLISMAT`
- `ct_TFT`
- `ct_LED`
- `mecanica`
- `PNxxxy-TRL`
